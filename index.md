# rclone-agentic

rclone-agentic is a private, single-user tool that keeps the owner's own Google Drive folder in sync with the owner's own iCloud Drive, using rclone.

It is not a public service and is not offered to anyone else. It only accesses the Google Drive account of its owner, with the owner's consent.
